## 🚀 Tech Stack

This website is built using a modern, high-performance stack designed for speed, SEO, and scalability:

* **Frontend Framework:** React.js / Next.js (or Vue/Nuxt)
* **Styling:** Tailwind CSS
* **Deployment & Hosting:** Vercel / Netlify
* **Content Management (CMS):** MDX / Sanity.io (Optional, adjust as needed)
* **Analytics:** Google Analytics / Plausible

---

## ✨ Features

* **⚡ Blazing Fast Performance:** Optimized images, code-splitting, and server-side rendering/static site generation.
* **📱 Fully Responsive:** Seamless user experience across mobile, tablet, and desktop devices.
* **🌙 Dark Mode Support:** Easy on the eyes with automatic and manual theme switching.
* **✍️ Dynamic Blog:** Technical articles markdown-powered or fetched via headless CMS.
* **🔍 SEO Optimized:** Correct meta tags, OpenGraph images, and semantic HTML for maximum search visibility.
